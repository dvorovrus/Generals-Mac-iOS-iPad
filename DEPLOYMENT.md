# Deployment standard

This file is the stable entry point for building, downloading, installing, updating and collecting logs for every maintained Apple variant.

Start here:

- Full guide: `docs/deployment/README.md`
- Variant catalog: `scripts/deploy/catalog.json`
- Windows / iPad CLI: `scripts/deploy/windows/generals-deploy.ps1`
- macOS CLI: `scripts/deploy/macos/generals-deploy.sh`

The rule is simple: do not memorize workflow names or artifact names. Use the catalog and the deployment CLI.
