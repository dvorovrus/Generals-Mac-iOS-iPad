# Development Diary - November 2026

## 2026-11-27 - Reforged iPadOS build experiment

Added a manual ARM64 device build for the pinned Reforged source, using its SDL3 GPU and Metal backend and an isolated app container. The patch adapts the Apple build for iPhoneOS, supplies a host fingerprint generator, and uses the app's Files and Application Support directories. The Windows host can check the patch and build script. The first iPhoneOS compile failed in the miniaudio C target because AVFoundation imports Objective-C headers. Updated the iOS-only patch to enable Objective-C and compile miniaudio.c as Objective-C, keeping other platform builds unchanged; CI revalidation remains required.
