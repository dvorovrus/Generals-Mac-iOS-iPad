## 2026-11-27 - Reforged iPadOS build experiment

Added a manual ARM64 device build for the pinned Reforged source, using its SDL3 GPU and Metal backend and an isolated app container. The patch adapts the Apple build for iPhoneOS, supplies a host fingerprint generator, and uses the app's Files and Application Support directories. The Windows host can check the patch and build script. The first iPhoneOS compile failed in the miniaudio C target because AVFoundation imports Objective-C headers. Updated the iOS-only patch to enable Objective-C and compile miniaudio.c as Objective-C, keeping other platform builds unchanged. The next macOS CI run passed the miniaudio step and exposed a forbidden iOS `system()` call in the legacy Windows nvdxt texture conversion helper. Guarded that developer-only helper on iOS with an explicit diagnostic; the existing desktop conversion remains unchanged. The third iPhoneOS compile progressed into the renderer and found Windows-only `DWORD` variables in `BaseHeightMap.cpp`; switched both to the renderer API's `RenderUInt32` type in the iOS patch. The fourth CI run linked `generals.app/generals` successfully but its packaging script still expected `device/generals`; updated the executable path to the CMake iOS app bundle and added a missing-file diagnostic. Bundle packaging and on-device validation remain required.
