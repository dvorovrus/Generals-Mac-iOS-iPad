# September 2026 Development Diary

## Overview

This diary tracks GeneralsX development work completed during September 2026.

## 25 September 2026

- Added an isolated Flutter launcher prototype under launcher_flutter.
- Added three selectable Zero Hour profiles: vanilla 1.04, Zero Hour Enhanced, and Contra X.
- Added a Windows GitHub Actions pipeline that generates the Windows runner, analyzes the launcher, creates a release build, packages it, and uploads a ZIP artifact.
- Kept launcher work separated from game-engine code; the native iOS profile-launch bridge remains a future integration point.
