# September 2026 Development Diary

## Overview

This diary tracks GeneralsX development work completed during September 2026.

## 25 September 2026

- Added an embedded WKWebView profile launcher that runs before Zero Hour engine initialization on iOS.
- Added profile-to-`-mod` routing for vanilla 1.04, Zero Hour Enhanced, and Contra X Beta 2 + Patch 1.
- Added an unsigned iOS launcher-shell packaging mode for GitHub Actions and Windows-side final IPA assembly.
- Added a Windows Python builder that reuses GameData from an existing full Zero Hour IPA and stages Enhanced/Contra as isolated overlays.
- Mirrored the current official Contra Launcher default archive selection instead of activating every mutually exclusive `.ctr` option.

- Reworked the standalone launcher prototype around Vite + React + TypeScript for faster Windows iteration.
- Added a clean widescreen Zero Hour launcher layout with one 16:9 hero image and three horizontal profile cards.
- Added poster acquisition for Zero Hour, Zero Hour Enhanced, and Contra X with local caching plus runtime fallbacks.
- Added a Vite Windows CI build that publishes a static launcher artifact.
- Kept the future iPad WKWebView profile bridge in the UI contract without touching game-engine code.
